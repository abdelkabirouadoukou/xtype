# What is xtype

xtype is a **local-first editor for math-heavy writing**. Everything — editing, math rendering, even PDF compilation via Typst/WebAssembly — happens inside your browser. Documents persist in IndexedDB on your device.

- Zero server compute: no accounts, no uploads, no timeouts
- Instant KaTeX preview while you type
- Publication-grade PDF export via the Typst compiler running in a web worker

Start with [Getting started](/docs/getting-started), or jump straight into [syntax basics](/docs/writing/basics).
