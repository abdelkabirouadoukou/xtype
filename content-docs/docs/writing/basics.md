# Syntax basics

xtype documents are Markdown with three math modes:

| Syntax | Meaning |
|---|---|
| `$...$` | Inline LaTeX math |
| `$$...$$` | Display (block) math |
| `::...::` | AsciiMath converted to LaTeX |

Markdown features supported: headings `#`, bold `**`, italic `*`, inline code, code fences, lists, blockquotes, links.

For the full list of math commands see the [command reference](/docs/writing/commands).
