# AsciiMath

Prefer plain-text math? Wrap it in double colons and it converts to proper typeset math:

- `::a/b::` → fraction
- `::sum_(i=1)^n i^3::` → summation
- `::oo::` → infinity

AsciiMath is great for quick notes; switch to LaTeX (`$...$`) when you need fine control.
