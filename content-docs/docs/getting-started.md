# Getting started

1. Click **Editor** (or "Start writing") — a fresh project is created instantly in your browser.
2. Type Markdown; mix in math:
   - Inline LaTeX: `$e^{i\pi} = -1$`
   - Display equations: `$$\int_a^b f(x)\,dx$$`
   - AsciiMath shorthand: `::a/b::`
3. Press `\` and a letter to search 100+ math commands with live previews.
4. Organize with folders in the left tree; create chapters with **+**.
5. Export: switch the preview to **PDF** (compiled by Typst) or use **print**.

Everything autosaves ~2 seconds after you stop typing, and again when you close the tab.
